# Mockups

Telas de rascunho usadas nas conversas de design, guardadas por transparência. São ilustrações em escala reduzida (telefones de ~300 px desenhando uma tela de 390 px), com links sem destino e tamanhos aproximados. Não são interface do produto: os limites reais (texto ≥ 16 px, botões ≥ 48 px, links para a checagem, contraste) estão nos documentos de design em `../specs/` e são verificados na implementação e nos testes.
